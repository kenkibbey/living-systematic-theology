**Prompt D supplemental addendum: findings.**
- **G3.** The detailed G3 report was **searched for and not located**, and no access restriction was encountered. The addendum corrects the V1–V8 report's wording that called it "inaccessible."
- **October 8, 2026.** These documents are an earlier upward challenge to the punishment grade. It was adjudicated **NOT SUSTAINED as required regrading**, with an optional lean toward eternal conscious punishment left open. Neither Issue #35 nor any A–D report had cited it.
- **Mark 9:43–48.** Jesus applies Isaiah 66:24's undying-worm and unquenched-fire language to **persons who go into Gehenna whole**, in the present tense. The addendum therefore reclassifies Mark 9:48 from a conditional-immortality text to a two-edged text. All four reports had missed this.
- **Comparative question.** Issue #35 asked whether eternal conscious punishment has stronger warrant than conditional immortality, and asked for only the smallest justified increase. Prompts B and C and the original D report did not answer this. The addendum answers it:
  - eternal conscious punishment has the stronger direct testimony about the final state;
  - conditional immortality has the broader destruction imagery;
  - on balance, Claude finds a **modest but contestable** edge for eternal conscious punishment, which it cannot verify as decisive and which falls well short of DEFENDED SYNTHESIS.
- **Recommendations.**
  - Before final disposition, explicitly adjudicate the comparative question, including whether Chapter 23 should say that a shared grade does not mean equal weight.
  - Add Mark 9:43–48 and Hebrews 10:27 (with its Isaiah 26:11 echo) to the coverage corrections.
- **Limits.**
  - No NA28 apparatus, lexicons, or commentaries.
  - The G3 report was not located.
  - The Jude 7 persons-reading is still untested.
  - The comparative weighting is contestable.
  - **Same-provider overlap:** Claude wrote the October 9 G1–G7 challenge that G3 answered, Prompt A, and both Prompt D documents. Testing by a different provider is recommended.
- **Correction of an administrative discrepancy.** The addendum also corrects the V1–V8 report's statement that the issue had no comments. That statement relied on a page-summarizing tool, while the GitHub API confirms that the A, B, and C notices were already posted.

**Method and status:** This is an **unadopted four-AI pilot**, not the current official challenge procedure. Publishing a role's argument is not an official LST verdict and changes no doctrine, confidence grade, or governing document.
