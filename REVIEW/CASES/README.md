## Archive standard (four-AI pilot)

- **Single issue:** Keep the person's challenge, respectful review notices, official adjudication, rebuttals and final disposition on the **original public GitHub issue**.
- **Public report files:** For each case create a unique `REVIEW/CASES/ISSUE-XXXX/` directory, a case `README.md`, and full report files (A/B/C/D) when the actual outputs have been received and verified.
- **First AI response:** Prompt A — **Challenger's Advocate** — builds the strongest honest biblical case **for the submitter's challenge against LST**, not against the person. Its first substantive AI review comment on the original issue points to its complete archived report.
- **Next responses:** Prompt B defends current LST by honest Revision Resistance; Prompt C independently adjudicates; Prompt D independently verifies. Disclose **actual** additional context if used rather than assigning private T.A.I.T. context automatically to future B reports. The original Issue #33 B report retains its documented historical project-assisted status. Each full report has its own dated file and a brief notice on the original issue.
- **Source and audit trail:** Preserve original AI findings, source limits, actual prompt version, role provider/model/date and limitations. Attribute any AI-added argument distinctly from the human challenger's actual assertions. Do not silently edit unfavorable passages.
- **Read-only reviewer publication:** If an examiner such as Gemini can read sources but not write to GitHub, the owner may give its complete original report to an authorized publishing intermediary. Attribute **the examination to the originating AI**, identify the intermediary separately, keep source-checking limitations intact, verify the Markdown write, and place the link on the original issue. A successful upload is not independent source verification.
- **Only a pilot:** Public archiving does not adopt the four-AI workflow as official challenge policy, determine biblical truth, or authorize changing the current Systematic.
