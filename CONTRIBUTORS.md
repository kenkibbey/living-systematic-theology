# Contributors and Acknowledgments

Living Systematic Theology (LST) welcomes people who contribute **biblical questions, challenges, corrections, research, review, writing, software work, and careful criticism**. A contribution does not have to agree with LST or result in a doctrinal change to deserve acknowledgment.

**Scripture is the final theological authority.** Recognition on this page neither confers doctrinal authority nor implies endorsement of LST by anyone listed.

## Why the GitHub Contributors panel may show different names

GitHub's built-in [repository Contributors graph](https://github.com/kenkibbey/living-systematic-theology/graphs/contributors) is calculated by GitHub from **commit authorship and its own attribution rules**. People who open issues are visible as issue authors and may receive GitHub profile activity credit, but are **not added to that repository commit graph merely for opening an issue**. A normal Markdown acknowledgments page cannot change GitHub's algorithm.

We will not add invented commit authors, false `Co-authored-by` trailers, or bot identities just to change the Contributors graph. The public issue authors, the credited research/AI producers, and the actual Git commit authors remain different kinds of contribution and should stay distinguishable.

For more about GitHub's counting rules, see [Viewing a project's contributors](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors) and [Profile contributions reference](https://docs.github.com/en/account-and-profile/reference/profile-contributions-reference).

## Participate

The best way to contribute is to [read the LST challenge pathway](CHALLENGE/README.md) and submit a well-supported biblical argument. **You do not have to use AI or agree with LST.** If you spot a missing public issue author or a credit that misrepresents someone's actual contribution, you can raise that in the [public issue list](https://github.com/kenkibbey/living-systematic-theology/issues).
